# 无效测量值与万用表收尾及调试按钮修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 GDM-9060 异常测量值显示与中止策略，补齐检测结束后的万用表状态恢复，并让非 Fake 模式运行页只显示终了与半实物复位按钮。

**Architecture:** 保持现有轻量架构，不新增第二套检测流程。异常测量值分类放在 `InspectionEngine` 内，万用表收尾语义扩展到 `IMultimeterDevice`，运行页按钮显示由 `TestPageViewModel` 暴露状态并在 `TestPageView.xaml` 绑定。

**Tech Stack:** C#、WPF、MVVM、CommunityToolkit.Mvvm、Serilog、SCPI over TCP、Modbus TCP、最小控制台测试。

---

## 1. 背景与问题

当前测试中出现以下问题：

```text
1. GDM-9060 返回 NaN、Infinity、负数或超量程大数时，程序把 double.TryParse 成功的值全部当成有效测量值。
2. 超量程大数会在运行页和保存弹窗中显示为极长数字，检查结果列显示异常。
3. NaN / -Infinity / 负电阻值这类明显异常没有按设备异常中止处理。
4. 检测结束后，万用表没有明确恢复到稳定空闲状态，也没有在终了、退出、急停、异常中止、程序关闭时退出远程控制。
5. 非 Fake 模式下仍显示 Fake 调试按钮；半实物联调阶段需要保留复位按钮，但按钮语义必须写清楚是临时模拟 DT121=1。
```

现有关键路径：

```text
InspectionEngine
  -> ReadResistanceRawAsync()
  -> ParseMeasurement()
  -> JudgeResult()
  -> StepCompleted
  -> TestPageViewModel.FormatMeasurementResult()

GwInstekGDM9060Driver
  -> InitializeResistanceModeAsync()
  -> InitializeContinuityModeAsync()
  -> ReadResistanceRawAsync()

TestPageViewModel / TestPageView.xaml
  -> 终了按钮
  -> Fake 调试按钮
  -> PLC DT121/DT122/DT123 轮询处理
```

## 2. 修复目标

### 2.1 无效值和异常值处理

| 原始值类型 | 导通模式检查结果 | 电阻值模式检查结果 | 处理策略 |
|---|---|---|---|
| `+Infinity` | `NG` | `NG` | 不在用户设定范围内，按 NG；不作为设备异常中止 |
| 超量程大数 | `NG` | `NG` | 不在用户设定范围内，按 NG；不作为设备异常中止 |
| `NaN` | `NG` | `NG` | 当前项显示 NG，随后中止并弹窗 |
| `-Infinity` | `NG` | `NG` | 当前项显示 NG，随后中止并弹窗 |
| 负电阻值 | `NG` | `NG` | 当前项显示 NG，随后中止并弹窗，电阻测量不应为负 |

运行页“检查结果”列对于这些特殊值统一显示：

```text
NG
```

判定列也显示：

```text
NG
```

日志必须输出原始值、点位名称、处理策略，例如：

```text
[检测流程][审计][INS-xxx] 万用表返回 NaN：点位 A3-A4 判定 NG，检测中止
[检测流程][审计][INS-xxx] 万用表返回负电阻值 -1Ω：点位 A3-A4 判定 NG，检测中止
[检测流程][审计][INS-xxx] 万用表返回超量程值 9.9E37：点位 A3-A4 判定 NG
```

### 2.2 万用表检测结束后的设置

单件方案所有项目正常检测结束后：

```text
不立即 SYST:LOC。
等用户在保存弹窗选择“保存”或“取消”后，让万用表保持远程可控，但回到稳定空闲的 2 线电阻准备态。
```

终了按钮、退出运行页、急停、异常中止、程序关闭时：

```text
让万用表退出远程控制，返回本地面板操作。
```

### 2.3 非 Fake 模式按钮显示

Fake 模式：

```text
显示完整调试工具：开始检测(Fake)、停止(DT122)、复位(DT121)、急停(DT123)。
```

非 Fake 模式：

```text
隐藏 Fake 调试工具。
只显示“终了”和“复位”。
复位按钮在半实物联调阶段临时写 DT121=1，注释必须写清楚，方便后续删除。
```

## 4. 设计细节

### 4.1 测量值分类

在 `InspectionEngine` 增加一个小型分类枚举和公开纯函数，便于最小测试直接覆盖：

```csharp
public enum MeasurementValueKind
{
    Normal,
    PositiveInfinityOrOverRange,
    NaN,
    NegativeInfinity,
    NegativeResistance,
    ParseFailed
}
```

新增公开静态方法：

```csharp
public static MeasurementResult ParseMeasurementForInspection(string rawText)
```

规则：

```text
OPEN：保留现有兼容，值按开路阈值处理。
SHORT：保留现有兼容，值为 0。
无法解析：ParseFailed，IsValid=false，中止。
NaN：IsValid=false，Kind=NaN，中止。
-Infinity：IsValid=false，Kind=NegativeInfinity，中止。
负数：IsValid=false，Kind=NegativeResistance，中止。
+Infinity 或 value > InputValidationHelper.ResistanceMaxValue：IsValid=true，Kind=PositiveInfinityOrOverRange，SpecialDisplayText=NG。
正常非负有限数：IsValid=true，Kind=Normal。
```

`MeasurementResult` 增加字段：

```csharp
public MeasurementValueKind ValueKind { get; set; } = MeasurementValueKind.Normal;
public bool ShouldAbortInspection { get; set; }
public string DisplayTextOverride { get; set; } = string.Empty;
```

说明：

```text
DisplayTextOverride="NG" 时，运行页检查结果直接显示 NG，避免 Infinity 或大数进入格式化。
ShouldAbortInspection=true 时，当前项先标记 NG 并回调 StepCompleted，再中止整轮并弹窗。
```

### 4.2 判定链路调整

`InspectionEngine.RunInspectionAsync` 当前读取后立即：

```text
ParseMeasurement -> if !IsValid abort -> JudgeResult
```

调整为：

```text
ParseMeasurementForInspection
  -> 如果 ShouldAbortInspection：
       Mark current point NG
       WritePointResultAsync(i, false)
       StepCompleted(current NG)
       AbortCurrentRunAsync(...)
       return result
  -> 否则正常 JudgeResult
```

`+Infinity` 和超量程大数：

```text
不走 ShouldAbortInspection。
JudgeResult 直接返回 NG。
若 ContinueTestingAfterNg=false，则按已有“NG 后停止”流程停止。
若 ContinueTestingAfterNg=true，则继续下一项。
```

### 4.3 运行页显示

`TestPageViewModel.FormatMeasurementResult()` 增加优先判断：

```csharp
if (!string.IsNullOrWhiteSpace(measurement.DisplayTextOverride))
    return measurement.DisplayTextOverride;
```

这样异常值不会进入：

```text
InputValidationHelper.FormatResistanceValue(value)
```

避免长数字撑破检查结果列。

### 4.4 万用表空闲态和本地态

`IMultimeterDevice` 新增：

```csharp
Task<bool> PrepareIdleResistanceModeAsync(CancellationToken ct = default);
Task ReleaseToLocalAsync(CancellationToken ct = default);
```

`GwInstekGDM9060Driver.PrepareIdleResistanceModeAsync` 指令：

```text
ABOR
*CLS
CONF:RES
SENS:RES:RANG:AUTO ON
SAMP:COUN 1
TRIG:COUN 1
TRIG:SOUR IMM
```

语义：

```text
保持远程可控。
回到稳定空闲的 2 线电阻准备态。
```

`GwInstekGDM9060Driver.ReleaseToLocalAsync` 指令：

```text
SYST:LOC
```

语义：

```text
退出远程控制，返回本地面板操作。
```

`DisconnectAsync()` 里在清理网络连接前尽力调用 `ReleaseToLocalAsync()`：

```text
程序关闭、设备管理器断开、主机释放时兜底让万用表回本地。
失败只记录 Warning，不阻断关闭。
```

`FakeInspectionHardware` 实现两个方法：

```text
只写 Warning 审计日志，返回成功。
```

### 4.5 调用万用表收尾的位置

正常完整检测结束：

```text
InspectionEngine 只负责完成检测和通知结果，不在引擎里恢复万用表。
TestPageViewModel.OnAllPinsTestedAsync 保存弹窗结束后调用 PrepareIdleResistanceModeAsync。
```

原因：

```text
用户要求“在用户选择保存或取消当前测试记录后”恢复设置，这个交互发生在 ViewModel。
```

异常中止、急停、终了、离开页面：

```text
TestPageViewModel 调用 ReleaseToLocalAsync。
GwInstekGDM9060Driver.DisconnectAsync 兜底调用 ReleaseToLocalAsync。
```

### 4.6 非 Fake 模式复位按钮

`IPlcDevice` 增加：

```csharp
Task<PlcOperationResult> RequestResetAsync(CancellationToken ct = default);
```

真实 PLC：

```text
写 DT121=1。
日志 Warning：[半实物联调][审计] 上位机临时写入 DT121=1，模拟 PLC 复位请求。
```

Fake：

```text
写 Fake DT121=1。
```

`TestPageViewModel` 增加属性：

```csharp
public bool IsFakeMode => _plcDevice is FakeInspectionHardware;
public bool IsRealSemiPhysicalMode => !IsFakeMode;
```

`TestPageView.xaml`：

```text
Fake 调试 Expander 绑定 IsFakeMode。
非 Fake 的“复位”按钮绑定 IsRealSemiPhysicalMode。
终了按钮始终显示。
```

半实物复位命令：

```csharp
[RelayCommand]
private async Task TriggerSemiPhysicalResetAsync()
```

注释必须写：

```text
半实物联调临时入口：真实 PLC 接入但现场复位按钮链路未完整联通时，
由上位机临时写 DT121=1 触发现有复位流程。
正式整机联调后删除该按钮和命令，复位应由 PLC/实体按钮触发。
```

## 6. 验收标准

```text
1. NaN、-Infinity、负电阻值：当前项检查结果显示 NG，判定 NG，日志记录原始值和原因，随后中止并弹窗。
2. +Infinity、超量程大数：当前项检查结果显示 NG，判定 NG，不作为设备异常中止；是否继续下一项由 ContinueTestingAfterNg 控制。
3. 检查结果列不再显示超长数字。
4. 正常完整检测结束后，保存/取消弹窗关闭后，万用表保持远程可控并回到 2 线电阻空闲态。
5. 终了、退出运行页、急停、异常中止、程序关闭时，万用表退出远程控制。
6. 非 Fake 模式隐藏 Fake 调试按钮，只显示终了和复位。
7. 半实物复位按钮写 DT121=1，并有清楚注释和 Warning 日志说明后续删除。
```

## 7. 不采用的方案

### 不采用：把异常值格式化成“超量程”

原因：

```text
本轮最新要求明确表格中检查结果为 NG。
运行页要直接显示 NG，避免操作员误解为仍有可用测量数值。
```

### 不采用：在驱动层直接判定 OK/NG

原因：

```text
驱动层只负责 SCPI 通讯和原始值读取。
OPEN/SHORT/电阻范围属于 InspectionEngine 的业务判定。
```

### 不采用：新建测量分类服务

原因：

```text
当前分类逻辑只服务 InspectionEngine，且需要访问检测判定上下文。
新服务会增加不必要层级。
```

### 不采用：程序一检测完就 SYST:LOC

原因：

```text
用户要求完整检测结束后先等待保存/取消，再恢复到远程 2 线电阻空闲态。
SYST:LOC 只用于终了、退出、急停、异常中止、程序关闭。
```
